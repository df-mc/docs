Understanding how Dragonfly works is key to building good servers. These docs cover the core systems you'll interact with daily.

## What's Different About Dragonfly?

If you're coming from PocketMine-MP or Nukkit, Dragonfly works quite differently. There are no global event listeners. No plugin.yml. No magical folder structure. Just Go code.

The main things to wrap your head around:
- **Per-player handlers** instead of global event listeners
- **Goroutines** for concurrent operations  
- **Composition over inheritance** (Go doesn't have classes)
